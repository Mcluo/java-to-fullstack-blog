## 核心原则：低风险 × 高时薪 × 异步交付

在职状态下时间是最大限制，不要接需要频繁对接、白天开会的项目。

---

## 最适合 Java/Python/JS 开发者的方向

### 1. 企业级外包（Java 吃香）

- 中小企业管理系统、ERP、OA 系统
- Spring Boot + 前端全栈报价高
- 单个项目 1-5 万很常见
- **接单渠道**：程序员客栈、本地 ISV 公司合作

### 2. 爬虫 / 数据处理（Python 天生优势）

- 非技术客户需求量巨大（电商选品、竞品监控）
- 单次需求 500-3000，周期短
- **注意**：避开明显违法场景（金融数据、个人隐私）

### 3. Node.js 后端 + 全栈（接海外单）

- Upwork 上 Node/Express/NestJS 需求很多
- 配合 React/Next.js 做全栈，时薪 $30-80
- **门槛**：英文沟通 + 稳定交付记录

### 4. AI 工具开发（当前风口）

- 对接 Claude/OpenAI API 成本极低
- 帮传统行业做 AI 自动化（客服机器人、文档处理、数据分析）
- 客单价高，非技术客户不懂行

## 推荐平台

### 国内平台

| 平台 | 地址 | 特点 |
|------|------|------|
| 程序员客栈 | proginn.com | 开发者专属，质量更高 |
| 猪八戒 | zbj.com | 最大，需求多但竞争激烈 |
| 码市 | codemart.com | 纯技术外包 |
| BOSS直聘 | 兼职频道 | 可找长期合作方 |

### 海外平台（单价高）

| 平台 | 地址 | 特点 |
|------|------|------|
| Upwork | upwork.com | 最大，时薪制 |
| Fiverr | fiverr.com | 按项目，适合标准化服务 |

**建议先从 `proginn.com`（程序员客栈）开始**，开发者氛围好，需求相对靠谱。

## 三阶段成长路径

### 第一阶段：快速变现（1-3个月）

接小而快的脚本/工具单：

- Python 爬虫、数据处理、自动化脚本
- 周期 3-7 天，晚上+周末就能搞定
- 目标：月入 **2000-5000**，积累口碑

### 第二阶段：提高单价（3-6个月）

Java 企业系统外包：

- 找 1-2 个稳定的 ISV 合作，做他们的外包开发
- 不用自己找客户，长期合作
- 目标：月入 **5000-15000**

### 第三阶段：被动收入（6个月后）

做一个小工具/SaaS：

- 利用本职工作中遇到的真实痛点
- Node.js + Next.js 快速出 MVP
- 哪怕月入 **500-2000** 也是纯被动

## 时间分配参考

```
工作日晚上  2小时  →  写代码交付
周六        4小时  →  集中攻坚
周日上午    2小时  →  沟通对接、复盘
```

每周实际可用约 **18 小时**，不要接超出这个量的单。

## 接单话术模板

```
您好，我有 X 年 Python/Java 开发经验，
看了您的需求，技术上完全可以实现。

请问：
1. 数据来源网站是哪个？
2. 需要采集哪些字段？
3. 交付格式 Excel 还是数据库？

确认需求后我可以给出准确报价和周期。
```

**不要一上来就报价**，先问清楚需求。

---

## 避坑指南

- 接单前**必须签合同**，明确需求范围（防需求蔓延）
- 先收 **30-50% 定金**
- 避开"先做出来再谈钱"的客户
- **第一单不用在意钱**，目标是完成交付 + 拿到好评，有了 3-5 个好评后报价可以翻倍

---

## 核心提醒

> 在职副业最大的风险不是技术，是**精力透支**导致主业受影响。
> 
> 建议设个硬性上限：副业收入不超过主业的 **50%** 之前，不加量。
